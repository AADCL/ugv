# WheelTech V5.1 轻量探索试验分支

更新：2026-09-11。

组织仓库为 `https://github.com/AADCL/ugv`，试验分支为 `experiment/wheeltech-light-exploration-v5.1`，基线为 `25e228c486495ed9c1f0048ece5b6d9d5f219c51`。当前部署对象为 `.123` 轮趣、ROS Noetic、`~/livox_fastlio`。本分支不修改 Scout 实现，也不替代主分支。

## 1. 改动与数据流

探索在线链路为：Livox → 原 FAST-LIO 与 Patchwork++ / Terrain Guard → 原局部障碍层及未膨胀观测导出 → 轻量观测记忆 → 前沿目标选择 → 原 GlobalPlanner 与探索配置的 TEB → 速度安全门 → 底盘。

`wheeltec_exploration/ObservedObstacleLayer` 继承原障碍层，约 2 Hz 发布 `/exploration/observed_local_map`。`observed_map_memory.py` 将未知、自由、障碍三态观测累积为 `/nav_static_map`；未知观测不擦除历史，有效的新自由观测可以清除旧障碍。探索仍需要这张轻量全局记忆图来判断前沿及规划跨局部窗口的路径。

探索期间不周期性进行全量 PCD 转图，不启动正式 PGM / 2.5D 地形生成、地形服务器或全局坡度层。原贝叶斯静态点云积累在内存中保留；探索自动保存周期设为 0，正常结束或 Ctrl+C 后保存 PCD 与轨迹，再由人工运行原地图转换工具。普通遥控建图的 30 秒自动保存，以及普通导航的 PGM、坡度代价与 TEB 功能保留。

探索全局 / 局部膨胀半径为 0.10 / 0.10 m；普通导航为 0.15 / 0.22 m，配置分开。探索目标检查完整车体覆盖区域是否已知且可通行。安全锁止不会自动重新使能。本分支也包含探索所需的监督器、速度安全、底盘适配包及此前修复。

公开功能入口只保留相机、遥控建图、重定位、导航、日志、探索六类；内部子模块移入 `launch/include/*.launch.xml`。供应商驱动示例保留。三大文档已对应整理。

## 2. 验证状态

已在 `.123` 编译通过，轻量记忆、探索监督器和前沿相关 21 项检查通过，六个集中入口解析结果与原包入口一致。

真实录包的 55 秒回放在独立 ROS master 上进行，没有连接底盘，也没有启动速度安全门：生成 99 次记忆地图、3 个探索目标、503 条规划速度指令，其中 496 条含正向速度、没有倒车指令。观测记忆节点单次处理平均 9.36 ms、最大 11.01 ms；此值不是整条点云或导航链路的耗时。

录包中车辆里程计静止，因此进度 / 振荡超时及重新选目标是预期现象。回放只能确认感知、记忆、目标与规划指令链路连通，不能证明实际到达、速度连续性、避障安全或整屋覆盖率。新的轻量链路完整实车探索仍待现场验收；旧版本的实车结果不算本版本验收。

## 3. 获取与启动

在开发电脑或新目录获取试验分支，按开发实施文档安装依赖并复制源码、编译。不要把整个仓库直接当作 catkin 的 `src`，不要覆盖正在使用的工作空间。

```bash
git clone --branch experiment/wheeltech-light-exploration-v5.1 \
  --single-branch https://github.com/AADCL/ugv.git ugv-wheeltech-experiment
```

完成安装后，原有包名启动方式不变。仅观察时：

```bash
source ~/livox_fastlio/devel/setup.bash
roslaunch wheeltec_exploration wheeltec_exploration.launch \
  map_name:=room_experiment_01 auto_start:=false
```

现场准备完成并告知人员后，以默认 `auto_start:=true` 启动才会在传感器和地图就绪后自动探索。不能同时运行独立建图、重定位或导航入口。正常结束并确认进程退出、PCD 保存后，沿用人工转换：

```bash
rosrun wheeltec_map_tools finalize_map.py room_experiment_01
```

集中 `launch/` 目录只需创建符号链接，源文件仍由各 ROS 包维护。新工作空间可按以下方式创建缺失链接，不覆盖已有文件：

```bash
cd ~/livox_fastlio
mkdir -p launch
for entry in \
  wheeltec_system_bringup/wheeltec_orbbec336l.launch \
  wheeltec_system_bringup/wheeltec_mapping.launch \
  wheeltec_system_bringup/wheeltec_localization.launch \
  wheeltec_navigation/navigation_teb.launch \
  wheeltec_navigation/nav_logging.launch \
  wheeltec_exploration/wheeltec_exploration.launch
do
  pkg=${entry%%/*}
  name=${entry#*/}
  test -f "src/$pkg/launch/$name" || exit 1
  if test ! -e "launch/$name" && test ! -L "launch/$name"; then
    ln -s "../src/$pkg/launch/$name" "launch/$name"
  fi
done
```
