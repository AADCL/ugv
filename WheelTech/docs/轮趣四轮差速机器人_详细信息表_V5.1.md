# 轮趣四轮差速机器人详细信息表 V5.1 · BATF-Nav

> 技术名称：`BATF-NavBayesianAccumulationTerrainFusionNavigation`；简称 **BATF-Nav**；英文展开 **Bayesian Accumulation Terrain Fusion Navigation**。见[统一技术说明](https://github.com/AADCL/ugv/blob/main/docs/BATF-Nav_V5.1.md)。本次整理沿用 V5.1，按功能保留启动入口并接入探索。

> 本表对应 2026-09-11 的 `.123`（`nrc15`）V5.1 工作空间和本地同步代码。正式架构为PGM唯一静态占据、保存高程坡度代价、当前帧局部地面分割、GlobalPlanner、TEB和起点安全逃逸；旧 `TerrainGlobalPlanner`、DWA及保存高程相对障碍不属于正式运行入口。

## 4. 正式入口

| 功能 | 命令 | 是否包含底盘 |
|---|---|---|
| 建图 | `roslaunch wheeltec_system_bringup wheeltec_mapping.launch map_name:=NAME` | 是 |
| 地图最终生成 | `rosrun wheeltec_map_tools finalize_map.py NAME` | 否 |
| 独立重定位 | `roslaunch wheeltec_system_bringup wheeltec_localization.launch map_name:=NAME` | 是 |
| 正式导航层 | `roslaunch wheeltec_navigation navigation_teb.launch map_name:=NAME` | 否；必须复用已运行的同名地图定位入口 |
| 导航日志 | `roslaunch wheeltec_navigation nav_logging.launch tag:=TAG` | 否，只记录 |
| 自主探索建图 | `roslaunch wheeltec_exploration wheeltec_exploration.launch map_name:=NAME` | 是，探索专用安全门和串口驱动；默认锁定 |
| Gemini 336L | `roslaunch wheeltec_system_bringup wheeltec_orbbec336l.launch` | 否 |

以上包含 6 个 launch 和一个保留的地图生成 rosrun 命令。其他必要子模块已移至 `launch/include/*.launch.xml`；7 个未使用的项目试验/重复入口已移除，供应商依赖 launch 保留。

普通手动 mapping 不得与已有地图定位/导航同时运行。探索在自己的入口内部组合建图与导航，不能在外部再次启动这些组件。正式导航需要一个 localization 加一个 navigation：localization 只启动一次，navigation 不包含 Livox、FAST-LIO、NDT 或底盘，因此不会抢占这些节点。

NX入口集合：`~/livox_fastlio/launch/`，恰好六个符号链接，分别指向表中各包的正式launch。源码参数只有一份；`launch/include/*.launch.xml`是内部依赖。已移除旧探索在线高程代码、整图刷新器、重复配置和过期测试，不影响普通导航的离线2.5D坡度层。根目录 `README.md`、`docs/`、`maps/`、`logs/`分别用于索引、当前文档、地图和运行记录。

## 5. 正式数据流

### 5.1 建图

```text
/livox/lidar + /livox/imu
  -> FAST-LIO2
  -> /cloud_registered + /Odometry
  -> wheeltec_pointcloud_mapper（公共贝叶斯静态点判定）
     +-> filtered_camera_init.pcd
         -> public_map.pcd（map 坐标，唯一静态权威）
            -> PMF 保守地面种子
            -> 鲁棒局部平面连续坡面生长
            -> 相对地面 0.04-1.50 m 障碍重分类
            -> map_raw/map PGM + terrain_2p5d 高程/坡度文件
```

正式建图只维护 `wheeltec_pointcloud_mapper` 产生的一份贝叶斯静态 PCD；默认不再启动在线 Patchwork++ 和分类累积器。最终转换直接从 `public_map.pcd` 提取 PMF 保守种子，并用二维支撑、局部平面残差与法向连续性约束恢复坡面，避免沿窄墙链爬到顶棚；障碍从同一静态源按相对高度提取，不需要第二次静态门控。只有诊断旧链路时才设置 `enable_online_terrain_diagnostics:=true`。导航实时避障使用原始实时点云，不经过建图静态滤波。

### 5.2 导航

```text
public_map.pcd + live cloud -> NDT -> map->odom
map_raw.yaml -> StaticLayer --------------------------+
terrain_2p5d cost -> TerrainCostmapLayer -------------+-> GlobalPlanner
live cloud -> Patchwork++ -> Terrain Guard ---------+-> local costmap -> TEB -> /cmd_vel
```

导航阶段先保持 localization 运行，再叠加纯 navigation；当前帧地面由 Patchwork++ 与 Terrain Guard 处理，局部障碍不依赖保存高程。

### 5.3 探索

```text
当前帧 -> 原 Patchwork++ / Terrain Guard -> 局部 ObstacleLayer -> Inflation -> TEB
                                               |
                          未膨胀已观测格 -> 轻量记忆图 -> 全局 costmap
                                                          -> 前沿适配/选目标
                                                          -> GlobalPlanner -> TEB
TEB /nav_cmd_vel -> 安全门 -> /wheeltec_driver/cmd_vel -> 探索底盘
原贝叶斯静态 mapper -> 内存积累 -> 正常退出保存 PCD/轨迹
                                     -> 人工 finalize_map.py -> 正式地图成果
```

只有一个 move_base、一个静态点云 mapper。探索在线不调用整图转换，不生成 PGM/2.5D，不启动高程服务器或全局坡度层；局部地面识别保留。前沿适配图只供搜索，真实路径仍查询 costmap。探索使用本次建图原点，不运行 NDT。正式地图格式及最终转换算法保留。

## 6. 节点

模式：M=手动建图，L=定位，N=普通导航系统，E=探索，C=相机，O=离线工具。E 复用 M 的静态积累和 N 的局部感知/规划组件，但不含 L 的 NDT。N 表示定位与导航的组合系统，不表示纯 navigation launch 会启动传感器。

| 节点 | 模式 | 输入 | 输出/职责 |

| 探索完成 | 满足连续无有效前沿、两次新地图且无活动目标时停车、保存并退出；完整房间实车自动结束仍待验收 |

## 14. 已知边界

- 地形文件是单层 2.5D，每个 XY 只能保存一个地面高程，不支持桥上桥下等多层拓扑。
- 普通导航加载离线地图；探索周期从同一贝叶斯静态 PCD 重新生成 PGM/高程。这不是另一个逐栅格贝叶斯高程融合器。
- 正式代价使用坡度和相对地面高度过滤后的分类障碍；粗糙度与坡面补偿高度残差只作诊断，不承诺完成楼梯语义识别。
- 实时障碍过滤依赖正确的安装外参和当前帧地面拟合；不查询保存高程，也不依赖 NDT 的 map 校正。全局路径仍依赖正确定位。
- 静态PGM不做预膨胀；global/local costmap运行时分别膨胀 `0.15/0.22 m`。TEB始终按完整footprint、`0.00 m` padding和 `0.04 m` 额外净空做碰撞约束。
- 车宽 `0.40 m`、门宽 `0.60 m` 时，物理余量仅约 `0.10 m/侧`；padding、TEB 净空、地图误差、门框突出和斜着进门都会消耗该余量。膨胀层是软代价，不替代 footprint 的硬碰撞判断。
- 相机当前独立运行，不进入 Livox 建图、重定位或导航。

## 15. 故障矩阵

| 现象 | 检查顺序 |
|---|---|
| 全屋不可通行 | 普通导航检查PGM/finalize与坡度层；探索检查 `/exploration/observed_local_map` -> `/nav_static_map` -> 全局costmap，不以在线finalize排障 |
| 全屋像自由空间 | PGM 阈值 -> unknown 是否保持 -> TerrainCostmapLayer 是否错误覆盖未知 |
| 有路径但不走 | local costmap -> TEB local plan -> footprint -> 障碍距离 -> `/cmd_vel` 发布者 |
| 坡道被当局部障碍 | 实时点云 -> 安装外参/sensor_height -> Patchwork++地面比例 -> Terrain Guard |
| 探索启动后不动 | `/exploration/state` -> 地图ready -> 有效前沿 -> 自动安全许可是否成功 -> `/wheeltec_safety/status` |
| 探索保护停车 | reason -> 当时真实局部障碍/原始点云/costmap -> 现场核对；不要自行缩小保护范围 |
| 坡度没有影响全局路径 | terrain map server -> slope layer 参数 -> global costmap -> 路径是否存在替代路线 |
| 没有 map TF | `/initialpose` -> map PCD -> NDT 输入 -> global localizer 日志 |
| 没有地形话题 | `terrain_2p5d.yaml` 及六层文件 -> terrain map server 日志 |
| 底盘无反馈 | `lsusb` -> `/dev/ttyACM0` -> udev -> dialout -> `/odom` |
| 相机无图像 | USB ID -> 订阅者 -> Orbbec 服务/诊断 -> USB 带宽 |
