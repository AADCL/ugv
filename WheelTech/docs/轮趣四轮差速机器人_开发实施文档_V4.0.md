> 用途：从一个空 ROS 工作空间复现当前轮趣小车系统。  
> 写法：每一阶段明确“复制什么、打开什么、修改什么、编译什么、测试什么”。

### 7.2 配置分类地图旁路

完整 PCD/NDT 建图保持不变，2.5D 分类建图作为同一正式入口中的并行支路。打开统一建图入口：

~~~bash
nano /home/nrc19/livox_fastlio/src/wheeltec_system_bringup/launch/wheeltec_mapping.launch
~~~

该入口同时启动原有 Livox、FAST-LIO、PCD 建图链，以及水平点云适配、地形分割和分类地图累积器。累积器同步订阅 `terrain_sensor` 地面/障碍和 `/Odometry`，通过 TF 组合 `camera_init→body→terrain_sensor` 后保存：

~~~text
terrain_ground_camera_init.pcd
terrain_obstacles_camera_init.pcd
~~~

累积器保存 Patchwork++ 原始 ground/nonground，不再保存 terrain_guard 二维标记点；terrain_guard 仍作为在线局部安全链工作。`finalize_map.py NAME` 默认会按 `wheeltec_geometry.yaml` 把分类 PCD 变换到 `map`，保留原 PCD、PGM/YAML 和 `terrain_cost` 兼容输出，同时生成真正的 `terrain_2p5d.yaml` 及高程、坡度、粗糙度、台阶、代价和置信度六层二进制栅格。分类 PGM 不得把全部 nonground 点直接投影为障碍：转换器在0.30 m邻域内估计局部地面，只接受相对地面0.08～1.50 m且同格至少3点的障碍，从而排除室内天花板和悬空噪声。`--terrain` 仅作为旧命令兼容参数保留；开发者只有明确需要旧二维输出时才使用 `--legacy-2d-only`。

2.5D 建图采用每格20%地面高度分位数、局部平面拟合和坡面补偿后的台阶残差。默认限制为22°坡度、0.08 m台阶和0.05 m粗糙度；孤立异常只写最高软代价，连续危险区域才写致命代价。全局规划器直接读取多层地图，边代价同时包含水平距离、高程变化和地形代价，并按0.32 m车体外接半径检查足迹。

开发时复制并检查以下文件：

~~~text

wheeltec_map_tools/src/pcd_to_pgm.cpp
wheeltec_map_tools/scripts/finalize_map.py
wheeltec_2p5d_navigation/config/terrain_builder.yaml
wheeltec_2p5d_navigation/src/terrain_map_builder_node.cpp
wheeltec_2p5d_navigation/src/terrain_global_planner.cpp
wheeltec_2p5d_navigation/src/terrain_costmap_layer.cpp

wheeltec_cloud_adapter/launch/cloud_adapter.launch

wheeltec_terrain_filter/src/terrain_map_accumulator_node.cpp

~~~

正式导航只使用 TEB。`wheeltec_navigation/navigation_teb.launch` 是唯一用户入口，它内部同时启动 PCD/NDT 重定位、PGM 兼容地图、持久化 2.5D 地图、TerrainGlobalPlanner、局部地形安全链和 TEB。入口设置 `global_plan_viapoint_sep=0.30`、`weight_viapoint=3.0`，使 TEB 跟随地形全局路径，同时保留动态避障能力；DWA 参数、启动文件和重复的 2.5D 包装入口已删除。

必须在 `extrinsics.yaml` 同时发布 `body→base_link` 和 `base_link→terrain_sensor`。`terrain_sensor` 与雷达同原点（相对base_link前0.10 m、上0.15 m），但RPY为0；禁止把它改成前倾20°，否则平地会被测成约20°坡面并污染障碍地图。Patchwork++ 的 `sensor_height` 是 `terrain_sensor` 原点到实际地面的总高度，不是这条TF的Z平移。本车base_link约离地0.15 m，因此配置为0.15+0.15=`0.30 m`。

### 9.2 TEB

~~~

轮趣原地转向角加速度较低，`move_base_2p5d_teb.yaml` 使用 `oscillation_timeout: 20.0`、`oscillation_distance: 0.05`。不要沿用 Scout 的 `5.0 s / 0.20 m`：原地调头时平移量很小，会被外层 move_base 提前误判为振荡；应先给 TEB 自身的振荡恢复足够处理时间。

### 9.3 Livox 在线障碍源

正式模式打开：

~~~text
wheeltec_2p5d_navigation/config/local_costmap_2p5d.yaml
wheeltec_2p5d_navigation/config/global_costmap_2p5d.yaml
wheeltec_navigation/launch/navigation_teb.launch
~~~

确认标障和清除使用两个独立 observation source：

~~~yaml
observation_sources: terrain_marking terrain_clearing

terrain_marking:
  topic: /terrain/obstacle_points
  marking: true
  clearing: false
  expected_update_rate: 0.20

terrain_clearing:
  topic: /terrain/clearing_points
  marking: false
  clearing: true
  expected_update_rate: 0.20
~~~

不得只接入障碍点而删除 clearing source，否则旧障碍可能残留。原始点云处理、PCD/NDT 重定位和普通 PGM 输出继续保留；局部规划器统一为 TEB。
