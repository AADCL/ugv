# 轮趣四轮差速机器人开发实施文档 V5.1

> 平台：Jetson NX、Ubuntu 20.04、ROS Noetic、Livox Mid-360、轮趣四轮差速底盘、Orbbec Gemini 336L。
> 工作空间：`/home/nrc19/livox_fastlio`。
> 本文面向第一次接触本项目的开发者，按“复制什么、打开什么、编译什么、测试什么”组织。

## 1. 当前正式方案

V5.1 保留 Livox、FAST-LIO2、PCD/NDT、PGM、分类点云和高程文件，但导航接口仍是成熟的 ROS1 二维 costmap：

```text
建图
Mid-360 -> FAST-LIO2 -> 完整 PCD -> NDT 地图
                         |
                         +-> 贝叶斯静态 PCD -> PMF 保守种子
                                                |
                                                +-> 鲁棒局部平面坡面生长
                                                +-> PGM 占据图
                                                +-> 每格高程、坡度和坡度代价

导航
PCD + NDT -> map->odom
PGM(map_raw) -> 静态占据/未知 ----------------------+
保存的坡度代价 -> TerrainCostmapLayer -------------+-> GlobalPlanner
实时点云 -> Patchwork++当前帧地面分割 -> Terrain Guard -+-> local costmap -> TEB -> /cmd_vel
```

关键约束：

- PGM 决定墙体、固定障碍和未知区域；坡度层只能给 PGM 已知格增加代价，不能把未知格变成自由格。
- 高程地图不是另一套导航入口，而是 PGM 的坡度代价来源和在线点云的地面高度参考。
- 全局规划器是 `global_planner/GlobalPlanner`，局部规划器只使用 TEB；DWA 和旧 `TerrainGlobalPlanner` 不在正式入口中。
- 导航阶段不启动 Patchwork++ 和 terrain_guard。动态障碍根据实时点相对保存地面的高度判定，避免固定 `base_link.z` 截取在坡道上误判。
- 本版本目标是平地、全局斜坡以及平地与坡道组合路段。楼梯语义和跨层地图不属于当前验收范围。

## 5. 配置外参与车体

### 5.1 Livox 外参

打开：

```text

```

车体采用前、左、上坐标。实测 `base_link` 离地 `0.15 m`，雷达离地 `0.30 m`，因此雷达位于车体中心前 `0.10 m`、上 `0.15 m`，雷达朝车头方向下压 `20 deg`。Patchwork++ 的 `sensor_height` 必须填写雷达相对地面的绝对高度 `0.30 m`，不能误填为外参高度 `0.15 m`。两处配置必须表达同一个刚体关系：

```yaml
x: 0.10
y: 0.00
z: 0.15
roll_deg: 0.0
pitch_deg: 20.0
yaw_deg: 0.0
```

`terrain_sensor` 与雷达同原点，但姿态与 `base_link` 一致，用于给 Patchwork++ 提供重力对齐点云。不要把 `terrain_sensor` 再设置成下压 20 度。

## 6. 配置地图生成

### 6.1 唯一建图入口

打开 `wheeltec_system_bringup/launch/wheeltec_mapping.launch`。它必须在同一入口中启动：

1. Mid-360；
2. FAST-LIO2；
3. `wheeltec_pointcloud_mapper`；
4. TF 与 pose adapter；
5. 轮趣串口底盘；
6. 默认不启动在线地形分割；
7. 只有设置 `enable_online_terrain_diagnostics:=true` 时才启动 `cloud_adapter`、Patchwork++ 和 ground/nonground 累积器；
8. `terrain_guard` 始终仅按需诊断。

正式建图必须共用一套静态点判定，数据流如下：

```text
/cloud_registered
  -> wheeltec_pointcloud_mapper（半径滤波 + 唯一可逆贝叶斯静态判定）
     -> filtered_camera_init.pcd
        -> public_map.pcd（map 坐标，唯一静态权威）
           -> 大窗口 PMF 保守种子
           -> 局部平面验证与连续坡面生长
           -> 相对地面 0.04-1.50 m 障碍重分类
           -> PGM + 2.5D 地图
```

正式建图无需在线地形分割。需要回归 Patchwork++ 时，设置 `enable_online_terrain_diagnostics:=true`，此时 `terrain_input_topic` 默认仍必须是 `/wheeltec/static_scan`；只有诊断静态滤波时才临时改为 `/cloud_registered_body`。由于静态判定要求至少 12 次命中并跨越 2 秒，启动后的前约 `2 s` 没有稳定静态输出属于正常现象。

`wheeltec_pointcloud_mapper` 是唯一动态/静态权威；三维 DDA 自由射线可以把已确认体素降级，并使整代精细地图点失效。`finalize_map.py` 直接读取这份贝叶斯静态 PCD：大窗口 PMF 先给出稀疏且保守的地面种子，随后每个候选格必须通过二维支撑、局部平面残差和法向连续性检查，才能沿不超过 `25°` 的坡面生长。该设计既能恢复 PMF 单独处理时会丢失的长坡，也阻断旧算法沿窄墙/渐变链爬到顶棚。最终按相对高度 `0.04-1.50 m` 重提取同源静态障碍；不再累积第二份不可修改的标签地图，也不再做重复静态门控。PGM 和 2.5D 只读取最终的 `terrain_ground_map.pcd` 与 `terrain_obstacles_map.pcd`。导航阶段继续使用 `/cloud_registered_body` 的实时点云做局部障碍检测。

完整 PCD 和分类 PCD 都自动保存，用户不需要调用手动 finish 服务。

### 6.2 PGM 参数

打开：

```text
wheeltec_map_tools/config/wheeltec_raw.yaml
wheeltec_map_tools/config/wheeltec_nav.yaml
```

正式导航读取 `map_raw.yaml`，静态障碍不预膨胀；全局 costmap 使用 `0.15 m` 膨胀保持窄门拓扑连通，局部 costmap 使用 `0.22 m` 膨胀。`map.yaml` 兼容图也不预膨胀，防止保存地图和运行时对同一门框重复膨胀。

分类 PGM 以每格 ground 点的 20% 高度分位数作为地面。nonground 点只有在附近 `0.35 m` 内存在地面，且相对地面高 `0.04-1.50 m`、同格至少 2 点时才成为障碍。该规则用于保留低矮障碍，同时排除天花板和孤立单点噪声。

### 6.3 高程和坡度参数

打开 `wheeltec_2p5d_navigation/config/terrain_builder.yaml`：

```yaml
resolution: 0.10
ground_height_percentile: 0.20
max_fill_radius_cells: 4
min_fill_neighbors: 3
fit_radius_m: 0.30
smooth_height_delta_m: 0.12
preferred_slope_deg: 5.0
max_slope_deg: 25.0
max_slope_cost: 80
min_lethal_neighbors: 4
fuse_static_obstacles: false
```

每格保存一个地面高度；小孔洞只在有足够邻居时填充；局部平面给出坡度；5 度以内不增加坡度成本，5-25 度逐渐增加软代价，持续超过 25 度才成为致命坡度。2.5D 不再重复融合 nonground 静态障碍，PGM 是全局静态障碍的唯一权威。坡面补偿高度残差继续保存为诊断层，不直接判死，避免稀疏点和填洞边缘把平地大面积误判为障碍。

默认流程不再累积分类点云。静态资格由 pointcloud mapper 统一要求至少 `12` 次命中、跨 `2.0 s` 且命中率不低于 `60%`；已晋升体素只有在至少 `8` 次自由射线并持续 `0.75 s` 后才降级。PGM 投影每个 `0.05 m` 栅格至少需要 `2` 个有效障碍点，以降低单点噪声，同时保留低矮障碍。保存的 `base_link` 轨迹在转换时提供半径 `0.20 m` 的自由走廊，但不能覆盖任何障碍格。

## 7. 配置正式导航

导航采用两个职责分离的入口。先启动 `wheeltec_system_bringup/launch/wheeltec_localization.launch`，让 Livox、FAST-LIO、NDT、TF 和底盘持续运行；再启动 `wheeltec_navigation/launch/navigation_teb.launch`。后者加载地图、坡度层、当前帧局部地面分割、GlobalPlanner、TEB、起点逃逸插件和 move_base，不得再次包含重定位或底盘节点。

### 7.1 全局 costmap

文件：`wheeltec_navigation/config/global_costmap_slope.yaml`。

```text
StaticLayer(/nav_static_map) -> TerrainCostmapLayer -> InflationLayer
```

- StaticLayer 读取 `map_raw.yaml`，负责自由、占据和未知。
- TerrainCostmapLayer 读取 `terrain_2p5d.yaml`，只在 PGM 已知格上叠加坡度成本。
- InflationLayer 的 `inflation_radius` 为 `0.15 m`，`cost_scaling_factor` 为 `3.0`，用于保证60 cm门在全局栅格上保持连通。
- 全局规划器为 `global_planner/GlobalPlanner`，`allow_unknown: false`。

### 7.2 局部障碍

文件：

```text
wheeltec_terrain_filter/config/patchworkpp_wheeltech.yaml
wheeltec_terrain_filter/config/terrain_guard_wheeltech.yaml
wheeltec_navigation/config/local_costmap_slope.yaml
```

`wheeltec_navigation_patchworkpp` 直接从当前 `/cloud_registered_terrain` 估计地面与非地面，`wheeltec_navigation_terrain_guard` 再按当前局部地面网格输出 `/terrain/obstacle_points` 和 `/terrain/clearing_points`。该链路不查询保存高程，也不依赖全局定位矩阵；局部 costmap 的 `observation_persistence` 为 `0 s`，避免历史点拖影。

局部 costmap 是 `odom` 下 `6 m x 6 m`、`0.05 m` 分辨率的滚动窗口，更新频率 `10 Hz`，膨胀半径 `0.22 m`。

### 7.3 TEB

文件：`wheeltec_navigation/config/teb_local_planner.yaml`。

| 参数 | 值 |
|---|---:|
| `max_vel_x` | 0.20 m/s |
| `max_vel_x_backwards` | 0.15 m/s |
| `max_vel_theta` | 0.40 rad/s |
| `acc_lim_x` | 0.20 m/s2 |
| `acc_lim_theta` | 0.30 rad/s2 |
| `min_obstacle_dist` | 0.04 m，60 cm 门洞模式下的车体边缘净空 |
| `inflation_dist` | 0.15 m，TEB 软代价距离，不是 costmap 膨胀 |

TEB 使用真实 polygon footprint。40 cm宽车体通过60 cm门洞时，每侧物理余量约10 cm；V5.1不增加 footprint padding，并要求4 cm额外动态净空。全局0.15 m膨胀只负责给出连通中心线，局部点云和TEB真实轮廓负责最终碰撞保护。

### 7.4 起点安全逃逸

`StartEscapeRecovery` 只在全局 footprint 碰撞、局部实时 footprint 安全、后方0.30 m走廊预检通过且存在新鲜后向点云覆盖时，以0.05 m/s倒退。倒车过程中持续检查后向覆盖和后方0.10 m，任一条件失效立即停车。当前Mid-360受车体遮挡，实测车后0.15～0.70 m近场为0点，因此未接后置传感器时插件会拒绝自动倒退。配置位于 `move_base_slope_teb.yaml`，源码位于 `wheeltec_2p5d_navigation/src/start_escape_recovery.cpp`。
